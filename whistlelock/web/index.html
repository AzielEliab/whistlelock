WhistleLock

Store the record. Chain the row. Release the packet locally.

This is a folder on this computer. You drop a file you already have. We hash it and chain the line. If you stop checking in, we copy a packet you already placed into released/. We do not mail it. You move the files.

THIS IS: a local vault + a chained ledger + a local dead-man copy. THIS IS NOT: a mailer, a rotating From: address, IP masking, a mixnet, an inbox scraper, a public website, UL, FoldLock, EmployeeLock, or GodLock. Dead-man copy is LOCAL. Hosted never holds whistle files. Demo drops are generic (“sample drop”).
